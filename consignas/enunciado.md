# Enunciado
Un complejo de cines dispone de varias salas enumeradas. **Por cada entrada vendida* se grabó un registro en un archivo histórico de ventas, donde cada registro contiene el nombre de la película,el número de sala y el año en el que se produjo la venta de dicha entrada. el archivo es de texto , con formato CSV.

Se solicita desarollar un programa para:

1. Informar cuál fue la pelicula más taquillera, indicando cantidad de entradas vendidas y porcentaje respecto al total.

2. Informar en qué año se verificó la mayor cantidad de espectadores, sin importar la película.

3. Imprimir un listado donde aparezca, año por año, la cantidad de espectadores que han ingresado a cada sala. Este listado deberá ordenarse segun el año de exhibición.

4. Imprimir un listado donde se visualice la cantidad de espectadores de cada película. Este listado debe ordenarse alfabéticamente según el nombre de la película.

5. Mostrar la combinacion sala/película más convocante de todo el período.

6. Indicar cuál fue la película que haya sido exhibida en mayor cantidad de salas. Mostrar todas las que correspondan.

> Se suministra un [archivo a modo de ejemplo](../codigo/basesDeDatos/peliculas.txt) llamado películas.txt con 100.000 registros. El programa debe funcionar con este o cualquier otro archivo con el mismo formato. El archivo no esta ordenado
